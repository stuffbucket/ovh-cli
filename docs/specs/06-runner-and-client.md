## Summary
Layer B is the user-facing shell: cobra commands, bubbletea TUI, a thin client wrapper over `github.com/ovh/go-ovh/ovh`, and the output formatter. It consumes Layer A's `apispace.json` read-only and never fetches the API surface itself.

## Goals
- Every HTTP call to OVH goes through one place (`internal/client.Client`).
- Commands are thin: cobra registration + flag parsing + delegate to a service package.
- Output is one formatter that all commands share.
- No file is over 100 lines without a documented exemption.

## Non-goals
- Re-implementing transport, signing, or OAuth2 refresh — go-ovh owns those.
- Hand-typing every OVH path in the runner — only the curated commands.

**Cycle rules**:
- `internal/auth` and `internal/client` must not import each other; they communicate via the `Credentials` value type passed by the composition root.
- `internal/schema` (Layer A) must not import any Layer B package.
- `internal/cli/<subtree>` packages may import Layer B packages and reach siblings via `*Deps`, but never each other directly.
- `tools/schemagen` is a separate Go module; nothing in the runtime binary may import it.

**Adding a package**: edit this table (layer + allowlist + exported symbols), update the `depguard` config to match, then any other PRD may reference the new package by name.

## Client wrapper
```go
type Doer interface {
    CallAPI(method, path string, reqBody, resBody any, needAuth bool) error
}

type Client struct {
    inner Doer       // *ovh.Client
    region string
    logger *slog.Logger
}
```
- Constructed by `internal/client.New(region, creds, opts...)`. The factory takes a `Credentials` value type, **never** a "loader" function — wiring lives at the composition root below, not inside `internal/client`.
- `Client.Do[T any](ctx, method, path, body)` wraps `CallAPI`, adds:
  - Request id (uuidv7) for logs.
  - Retry with exponential backoff on 5xx, 429 (honors `Retry-After`); never retries 4xx other than 429.
  - Translates `ovh.APIError` to typed errors keyed by HTTP status (so commands can branch on `errors.Is(err, client.ErrNotFound)`).
  - Slog with redaction filter for AK/AS/CK/Bearer.

## Composition root and layer rules
`internal/cli/deps.go` is the composition root. It owns the wiring so neither `internal/auth` nor `internal/client` needs to import the other:

1. Load config via `internal/config` (which reads paths from `internal/xdgpaths`).
2. Load credentials via `internal/auth.LoadCredentials(ctx, region, profile)` — env/flag/keyring/file order per [PRD-04 §Read precedence](04-config-and-storage.md#read-precedence-for-credentialsconfig).
3. Construct the typed client: `internal/client.New(region, creds, opts...)`.
4. Construct the output renderer.
5. Open the schema querier: `internal/schema.OpenCache(region)`. For `ovh schema refresh`, the cobra command resolves both the API endpoint URL and `ValidationHostPattern` from `internal/auth.RegionByID` and passes them as the `endpoint` and `allowedHosts` parameters to `internal/schema.Refresh(ctx, region, endpoint, allowedHosts)` — Layer A never imports `internal/auth`.
6. Hand the bundle (`*cli.Deps`) to cobra commands.

**Mid-session credential rotation (TUI)**: the TUI's root model owns the current `*client.Client`. When a `tea.Cmd` detects 401 it dispatches `refreshTokenCmd` (returns `tokenRefreshMsg{newCreds, err}`); on success the root model's `Update` reassigns `m.client = client.New(region, newCreds)` and re-issues the original fetch as a fresh `tea.Cmd`. **All swap visibility crosses the bubbletea message loop** — never via direct field mutation from a goroutine. This makes the swap data-race-free without a mutex: `Update` is single-threaded, and any in-flight `tea.Cmd` reads its own copy of the pointer captured at dispatch. `internal/auth` never holds a reference back to `*cli.Deps`. Concurrent 401-driven refreshes coalesce through `auth.RefreshOAuth2`'s singleflight invariant (PRD-03), so even if two `tea.Cmd`s race they trigger at most one RPC.

Strict rules:
- `internal/client` does **not** import `internal/auth`.
- `internal/auth` does **not** import `internal/client`. Auth-bootstrap HTTP calls (`POST /auth/credential`, validation poll, OAuth2 token exchange) use `go-ovh`'s `*ovh.Client` primitives directly inside `internal/auth/flow.go` and `internal/auth/oauth.go`.
- The two layers communicate via the `internal/auth.Credentials` value type only.
- No package outside `internal/client` is allowed to call OVH directly except `internal/auth` (bootstrap) and `internal/schema` (anonymous discovery, per PRD-05).

## Pagination
- OVH's primary list pattern returns an array of ids; subsequent calls fetch each.
- Helper: `client.PaginateIDs(ctx, listPath, fetchPath)` returns a streaming channel.
- Some endpoints (`/cloud/project/{id}/instance`) are arrays of full objects — handled by a different helper.

## Output formatter
- One `output.Renderer` constructed from `--output` + TTY detection.
- `Render(any)` accepts any struct; reflect-based table builder reads `ovh:"colName"` tags.
- JSON/YAML modes use stdlib encoders.
- Template mode: `text/template` with sprig-subset helpers.
- `--jq` post-processes JSON via `itchyny/gojq`.
- Redaction: any string matching the credential redaction list (AK/AS/CK/Bearer) is replaced with `****` *unless* `--show-secrets`.

## TUI shell
- See PRD-02 for UX. Mechanics:
- `tui/app.go` constructs root model from `cli.Deps`.
- Each pane is `tea.Model`; root dispatches on focus.
- API calls return `tea.Cmd` producing typed result messages — keeps render path pure.
- TUI shares `internal/client.Client` and `output.Renderer` with CLI; no parallel implementations.
- Command palette (`:`) and list filter (`/`) use `github.com/sahilm/fuzzy`; this dep is **Layer B-only** and must never be imported from `internal/schema`.

## Catalog cache
- Separate from schema cache; lives at `$XDG_CACHE_HOME/ovh/catalog/<region>/`.
- Holds flavor/image/region metadata so list commands don't refetch on every invocation.
- TTL from `default.cache_ttl_hours`.

## Cross-cutting conventions
Implementation-level invariants that span multiple packages. **Single source of truth** for each. Other PRDs cite by name; they do not redefine.

### Request id
- Format: UUIDv7 (time-ordered).
- Generated once per command invocation in `internal/cli/deps.go`.
- slog log field name: `request_id`.
- **Not** sent as an outbound HTTP header in v0.1 (OVH does not echo it and it would interfere with request signing).
- Appears in error messages only under `--debug`; appears in the audit log when that lands per PRD-12.

### Struct tag grammar
DTOs in `internal/client/types/` and any user-facing struct rendered by `internal/cli/output.Renderer` carry the `ovh` struct tag:

```go
type Instance struct {
    ID     string `ovh:"id"`
    Name   string `ovh:"name,sort"`
    Status string `ovh:"status,width=10"`
    Region string `ovh:"region,hide"`
}
```

Grammar: `ovh:"<colName>[,<modifier>...]"`. v0.1 modifiers: `sort` (default sort column), `width=<n>` (table-mode width hint), `hide` (omit by default; `--all-cols` reveals). Unknown modifiers are a test-time error. `tools/schemagen` emits only the bare `ovh:"<colName>"`; manual annotations add modifiers.

### Retry policy
The `internal/client/retry.go` wrapper applies these rules to every `*ovh.Client.CallAPI` invocation:
- **Retry on**: 5xx, 429, transport errors (`io.EOF`, `net.OpError` with `Timeout()==true`).
- **Never retry**: 4xx other than 429 (notably 401/403, 404, 409, 412).
- **Max attempts**: 4 (1 initial + 3 retries).
- **Backoff**: exponential, base 500ms, multiplier 2.0, max delay 30s, full jitter.
- **`Retry-After` parsing**: prefer integer seconds; fall back to RFC 1123 HTTP-date; cap at 60s; on parse failure, use the standard backoff schedule.
- **Total deadline**: bounded by `default.timeout` minus elapsed; if exceeded, return the last HTTP error wrapped with `context.DeadlineExceeded` as the cause.
- Retry sleeps are interruptible via `ctx.Done()`. On context cancellation during a sleep, return `ctx.Err()` (NOT the last HTTP error). On cancellation during a request, return whatever go-ovh's `CallAPI` returned. **Exit-code mapping**: `context.Canceled` → `exitcode.Generic`/`INTERNAL`; `context.DeadlineExceeded` → `exitcode.Network`/`NETWORK`.
